# دفترکار من

اپلیکیشن اندرویدی فارسی برای ثبت مشتری، سفارش و گردش مالی، با ذخیره‌سازی محلی SQLite و بدون نیاز به اینترنت هنگام استفاده.

## ساخت APK
با هر push به شاخه main یا اجرای دستی workflow با نام **Build Android APK**، گیت‌هاب پروژه را در فضای ابری می‌سازد و APK را به‌صورت Artifact قرار می‌دهد.

## نکته مهم
این نسخه MVP آزمایشی است. داده‌ها فقط روی همان گوشی ذخیره می‌شوند. حذف برنامه یا پاک‌کردن داده‌های آن ممکن است اطلاعات را از بین ببرد؛ پیش از انتشار عمومی باید قابلیت پشتیبان‌گیری/بازیابی داخل اپ و آزمون روی چند دستگاه اضافه شود.
