# دفترکار من

اپلیکیشن اندرویدی فارسی برای مدیریت مشتری‌ها، سفارش‌ها و گردش مالی. اطلاعات در نسخه فعلی به‌صورت آفلاین و روی همان گوشی ذخیره می‌شود.

## امکانات نسخه ۰.۲.۰
- داشبورد مانده حساب، مجموع دریافتی و هزینه
- ثبت و حذف مشتری
- ثبت و حذف سفارش همراه مبلغ و وضعیت
- ثبت دریافتی و هزینه و مشاهده گردش مالی
- پشتیبانی از اعداد فارسی، عربی و انگلیسی در مبلغ‌ها
- تهیه نسخه پشتیبان JSON از مشتری‌ها، سفارش‌ها و گردش مالی
- بازیابی نسخه پشتیبان با اعتبارسنجی فایل و تأیید جایگزینی اطلاعات

## تهیه نسخه پشتیبان
از منوی ابزارها در بالای برنامه گزینه «تهیه نسخه پشتیبان» را بزن و فایل JSON را در حافظه گوشی یا فضای ابری خود ذخیره کن. این کار را مرتب انجام بده.

## بازیابی
از همان منو «بازیابی نسخه پشتیبان» را انتخاب و فایل JSON ساخته‌شده توسط برنامه را انتخاب کن. بازیابی، اطلاعات فعلی را جایگزین می‌کند؛ بنابراین قبل از آن از اطلاعات فعلی هم پشتیبان بگیر.

## ساخت APK
هر تغییر در شاخه main به‌صورت خودکار با GitHub Actions ساخته می‌شود. فایل خروجی در بخش Artifacts اجرای موفق workflow قرار می‌گیرد.

## محدودیت‌های نسخه فعلی
- اطلاعات بین دستگاه‌ها همگام‌سازی نمی‌شوند.
- نسخه پشتیبان خودکار زمان‌بندی‌شده نیست و باید دستی تهیه شود.
- این نسخه هنوز روی چند مدل گوشی و نسخه اندروید آزمایش میدانی نشده است.
- پیش از انتشار عمومی باید متن حریم خصوصی، تصاویر فروشگاه، آیکون نهایی و تست نصب/بازیابی تکمیل شوند.
